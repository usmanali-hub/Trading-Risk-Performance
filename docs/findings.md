# Findings

This document is populated from the generated dataset when the analysis pipeline is executed. The project is designed to compare trading behavior rather than simply report a headline return.

## Questions answered

1. Which strategy has the highest total P&L and expectancy?
2. Which instrument contributes most to results?
3. Which session has the strongest average trade outcome?
4. Which market regime creates the largest drawdowns or weakest expectancy?
5. How concentrated are gains and losses?
6. What does the equity curve reveal about consistency?

## Interpretation principles

A strategy should not be judged by win rate alone. Profit factor, expectancy, drawdown, variability, and concentration should be considered together.

Because the underlying dataset is synthetic, findings are for portfolio demonstration and analytical practice only.
