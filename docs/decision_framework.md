# Decision Framework

## Performance
Start with total P&L, average trade, win rate, profit factor, expectancy, and return on risk.

## Risk
Then evaluate maximum drawdown, drawdown percentage, tail-loss measures, loss streaks, volatility, and recovery factor.

## Concentration
Check whether a small share of winning trades contributes a disproportionate share of total positive P&L.

## Segmentation
Compare strategy, instrument, session, and market regime before deciding where performance is consistent or fragile.

## Action logic
- Strong performance + controlled drawdown → candidate for deeper validation.
- Strong performance + concentrated winners → investigate dependency on outliers.
- Weak performance + high drawdown → prioritize risk-control review.
- Mixed segment performance → investigate regime or execution sensitivity.

All analysis is based on synthetic data and is not a claim about future trading performance.
