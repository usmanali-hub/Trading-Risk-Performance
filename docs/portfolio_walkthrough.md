# Recruiter / Interview Walkthrough

## 30-second explanation

“I built a reproducible trading analytics pipeline using synthetic trade-level data. It measures return, expectancy, drawdown, tail risk, recovery, concentration, and segment behavior so performance can be evaluated through a risk lens rather than headline P&L alone.”

## What to show first

1. `src/performance_analysis.py` — performance metrics.
2. `src/risk_analysis.py` — tail risk and drawdown logic.
3. `sql/trading_analysis.sql` — segmentation queries.
4. `reports/executive_dashboard.md` — executive communication.
5. `tests/test_risk_analysis.py` — automated validation.

## What this proves

- Understands financial performance metrics.
- Can distinguish return from risk.
- Can identify concentration and tail exposure.
- Can segment performance before making decisions.
- Can test analytical code and maintain reproducibility.
